# Frontend Design

Create distinctive, production-grade web interfaces through intentional design thinking.

## Core Approach

Before writing any code, understand:
- **Purpose**: What is this interface for? What problem does it solve?
- **Audience**: Who uses it and in what context?
- **Tone**: What feeling should it evoke — trust, energy, calm, playfulness, authority?

Then commit to a **bold aesthetic direction**. Don't hedge toward the middle. A strong vision executed well beats a cautious one executed perfectly.

## Design Dimensions

### Typography

Choose fonts that are beautiful, unique, and interesting. Avoid generic families like Arial and Inter — they carry no personality. Seek typefaces with character that reinforce the aesthetic direction.

Consider: weight contrast, size hierarchy, letter-spacing, and whether a serif/sans/display combination creates more visual interest than a single family.

### Color

Build a cohesive color system rather than picking isolated colors. Consider:
- A primary palette with intentional relationships (analogous, complementary, triadic)
- How color communicates state and hierarchy
- Mood: saturated and vivid vs. muted and refined vs. high-contrast and stark

Avoid clichéd gradients (generic blue-purple, teal-to-green) that signal "AI-generated default."

### Spatial Composition

Break from predictable grid layouts when the concept calls for it:
- Asymmetry and deliberate imbalance
- Overlapping elements
- Diagonal flow or rotated elements
- Grid-breaking hero sections
- Generous or compressed spacing used intentionally, not by default

### Motion & Interaction

Focus animation on high-impact moments rather than sprinkling effects everywhere:
- One well-orchestrated page load with staggered reveals
- Meaningful transitions that reinforce spatial relationships
- Micro-interactions that reward attention without distracting

Avoid: decorative animations that don't serve the user or the aesthetic.

### Atmosphere & Detail

Small details create richness:
- Texture, grain, or noise layers
- Subtle shadows with intentional color (not just black opacity)
- Border treatments, dividers, and negative space as design elements
- Consistent radius/corner language throughout

## What to Avoid

- **Generic AI aesthetics**: The defaults that emerge from prompting without direction — overused typefaces, blue-purple gradients, card-grid layouts, centered hero with big headline and CTA
- **Predictable layouts**: If it's the first structure you'd reach for, ask whether something more distinctive serves the concept better
- **Scattered effects**: Motion, shadows, and gradients that don't cohere into a unified visual language
- **Context-free design**: Applying the same aesthetic regardless of what the product is or who it's for

## Implementation Philosophy

Match code complexity to the aesthetic vision:
- **Maximalist / elaborate designs**: Invest in the implementation — custom animations, layered effects, detailed components
- **Minimal / refined designs**: Restraint and precision are the craft — no unnecessary flourishes, every element earns its place

The measure of success is intentionality and cohesion, not intensity. A spare, typographic design executed with discipline is as strong as a richly layered one — as long as the choices are purposeful.

## Process

1. Clarify purpose, audience, and tone before starting
2. Declare the aesthetic direction explicitly (e.g., "brutalist editorial," "warm craft marketplace," "clinical precision tool")
3. Make distinctive choices in each dimension — typography, color, layout, motion
4. Ensure all choices reinforce each other and the declared direction
5. Review: would this be mistaken for a generic AI-generated interface? If yes, push further
