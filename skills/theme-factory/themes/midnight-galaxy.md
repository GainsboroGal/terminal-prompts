# Midnight Galaxy

Deep purples and mystical tones for impactful, dramatic presentations.

## Color Palette

| Role | Name | Hex |
|------|------|-----|
| Rich dark base | Deep Purple | `#2b1e3e` |
| Mystical mid-tone | Cosmic Blue | `#4a4e8f` |
| Soft accent | Lavender | `#a490c2` |
| Light highlights / text | Silver | `#e6e6fa` |

## Typography

- **Headers**: FreeSans Bold
- **Body**: FreeSans

## Recommended Applications

Entertainment industry, gaming presentations, nightlife venues, luxury brands, creative agencies.
