# Tech Innovation

A high-contrast, forward-thinking design for modern technology presentations.

## Color Palette

| Role | Name | Hex |
|------|------|-----|
| Vibrant primary accent | Electric Blue | `#0066ff` |
| Bright highlight | Neon Cyan | `#00ffff` |
| Deep background | Dark Gray | `#1e1e1e` |
| Text / clean contrast | White | `#ffffff` |

## Typography

- **Headers**: DejaVu Sans Bold
- **Body**: DejaVu Sans

## Recommended Applications

Tech startups, software launches, innovation showcases, AI/ML presentations, digital transformation content.
