# Forest Canopy

A grounded, natural design inspired by dense forest environments — earthy and organic.

## Color Palette

| Role | Name | Hex |
|------|------|-----|
| Main dark shade | Forest Green | `#2d4a2b` |
| Muted accent | Sage | `#7d8471` |
| Lighter highlights | Olive | `#a4ac86` |
| Backgrounds / text | Ivory | `#faf9f6` |

## Typography

- **Headers**: FreeSerif Bold
- **Body**: FreeSans

## Recommended Applications

Environmental presentations, sustainability reports, outdoor brands, wellness content, organic products.
