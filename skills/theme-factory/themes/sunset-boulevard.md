# Sunset Boulevard

A warm, dynamic design inspired by golden hour aesthetics — energetic and imaginative.

## Color Palette

| Role | Name | Hex |
|------|------|-----|
| Main accent | Burnt Orange | `#e76f51` |
| Secondary warm accent | Coral | `#f4a261` |
| Backgrounds / highlights | Warm Sand | `#e9c46a` |
| Text / dark contrast | Deep Purple | `#264653` |

## Typography

- **Headers**: DejaVu Serif Bold
- **Body**: DejaVu Sans

## Recommended Applications

Creative pitches, marketing presentations, lifestyle brands, event promotions, inspirational content.
