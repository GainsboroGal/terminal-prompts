# Modern Minimalist

A clean and contemporary theme with a sophisticated grayscale palette for maximum versatility.

## Color Palette

| Role | Name | Hex |
|------|------|-----|
| Primary dark | Charcoal | `#36454f` |
| Medium accents | Slate Gray | `#708090` |
| Backgrounds / dividers | Light Gray | `#d3d3d3` |
| Text / clean backgrounds | White | `#ffffff` |

## Typography

- **Headers**: DejaVu Sans Bold
- **Body**: DejaVu Sans

## Recommended Applications

Tech presentations, architecture portfolios, design showcases, modern business proposals, data visualization projects.
